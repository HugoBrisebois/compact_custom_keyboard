# Compact Keyboard1 - User Guide


this is your user manual in which you will learn how to make your keyboard a keyboard and learn it's ins and outs.

# what are the specs of this keyboard

this keyboard is powered by a rp2040 raspberrypi Pico with the functionality of being a wired keyboard having a micro usb power connector. the keys on this keyboard are kailth chic mini hotswap meaning that you can always change the keys if you don't like them, as well as have underflow GRB leds from adafruit


# quick start

in order for your keyboard to be a keyboard you will need to flash it so:

- step 1: plug your keyboard into your laptop or desktop and hold the boot button for two seconds. 

- step 2: after holding the boot button of your raspberrypi Pico, it will appear as a disk in which after downloading the .hex file from my repo, you will drag and drop the .hex file or you will copy paste the file in to the raspberrypi Pico disk that has appeared
- step 3: unplug the keyboard and wait 10 seconds. after which, you should be able to plug it back in and start using it, the LEDs should come in, if not I am still working on this problem

# functions of this keyboard 

this keyboard is a 60% layout with 62 keys to accommodate the to space bars
